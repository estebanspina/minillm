# Cómo contribuir a MiniLLM

Este repositorio es una herramienta educativa. Priorizamos que el código sea legible y ejecutable en CPU, sin pesos preentrenados.

1. Elegí un issue o proponé un ejercicio concreto.
2. Creá una rama descriptiva (`feat/...`, `docs/...`, `fix/...`).
3. Incluí una explicación del aprendizaje esperado y comandos de reproducción.
4. Agregá pruebas cuando cambies código.
5. Abrí un Pull Request pequeño y explicá cómo lo verificaste.

## Checklist para PR

- [ ] Funciona localmente en CPU.
- [ ] No requiere API ni modelo preentrenado.
- [ ] Documenta dependencias y limitaciones.
- [ ] Incluye instrucciones y evidencia de ejecución.
- [ ] No contiene datos privados ni archivos de pesos.

Los errores, hipótesis fallidas y resultados inconsistentes son oportunidades de aprendizaje; documentalos con precisión.
